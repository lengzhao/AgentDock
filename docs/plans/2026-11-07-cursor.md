# Cursor ACP 接入

沿用已批准的可替换 ACP 运行架构，使用 Cursor 原生 cursor-agent acp，认证方法 cursor_login。解析本机 CLI，避免 registry 归档相对 cmd 被错误视作安装路径；agent 通用名字仅在验证 Cursor ACP help 后使用。

新增 agents add <id> 入口，保留其他 Agent、默认选择和平台连接；显式 --default 才修改默认。Cursor 支持 cursor/cursor-acp 输入，保存规范 ID cursor。补充登录提示、检测、native/alias/非 Cursor 冲突与配置保留回归测试。真实 fake Cursor 认证+MCP 定时器 E2E 覆盖运行接缝。

仅做本机 initialize 探测，不触发真实 prompt 或登录操作。专属 Cursor UI 扩展不在标准 ACP 支持声明内。全量/race/vet/build 检查后更新本地二进制。
