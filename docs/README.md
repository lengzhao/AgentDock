## 当前决策

- 独立 GitHub 项目，基于 AgentKit，不引用 agent-harness。
- 复用已有 Agent，而不是重新实现一套模型执行循环。
- 产品需要安装引导、平台授权与凭据获取、系统凭据存储、后台常驻和诊断。
- 长期覆盖主流操作系统与主流 IM；首版明确收敛为 **macOS + Lark**。
- Claude Code、Codex 是首批建议接入目标，Pi、Grok、Kimi 等进入后续兼容矩阵。首批 Agent 名单仍属建议。
- 敏感凭据使用 `zalando/go-keyring`；不得静默降级为普通明文文件。
- 可替换能力一律收敛成槽位（凭据、服务、引导 UI、二维码、状态库、ACP 适配器目录），槽位接口由本项目定义，第三方库只出现在适配器内部；kind 统一 `agentdock/*` 前缀。
- Agent 接入以 ACP 为准，适配器通过官方 registry 目录驱动（含各平台 sha256），不逐个硬编码。
