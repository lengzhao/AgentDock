# AgentDock 产品需求

版本：v0.1 需求草案；日期：2026-11-07。本文整理已确认需求与建议，不代表所有方案已获批准，也不代表功能已实现。

## 1. 目标与范围

让用户在一次可恢复的配置引导后，通过 Lark 使用本机已有 Agent；关闭终端后仍可运行，出现问题时可查询状态并完成修复。

### 用户已确认

- 独立项目，放到 GitHub；不引用 agent-harness。
- 直接使用 Claude/Codex/Pi/Grok/Kimi 等已有 Agent。
- 提供守护进程、平台引导和尽可能自动的 key/secret 获取。
- 通过 go-keyring 存储敏感凭据。
- 长期面向主流环境、主流 IM；首版可以仅支持 **Lark + macOS**。

### 建议的首版边界

- macOS 用户级服务，Apple Silicon 与 Intel 构建分别验证；不承诺关机、休眠或用户退出登录时仍在线。
- Lark 国际版自建应用机器人；飞书中国版单列为后续兼容目标。
- Claude Code 与 Codex 为首批建议 Agent；先验证一个完整链路，再通过同一契约接入第二个。
- 单机、单 OS 用户、一个 Lark 应用、多个会话；默认每个新会话选定一个 Agent。
- 私聊为必验路径；群聊仅显式 @机器人并通过配置允许时触发。
- CLI/TUI 引导优先，不把桌面 GUI、Web 管理台或云服务作为首版依赖。

## 2. 主要使用场景

1. 已安装并登录 Agent 的用户，扫码连接 Lark，选择工作目录后直接聊天。
2. 未安装 Agent 的用户，由引导展示官方安装方式或经过确认的安装动作，完成原生登录并验证。
3. 用户关闭终端、重新登录 Mac 后，机器人恢复连接并能继续使用已有会话。
4. Agent 等待工具审批时，用户在 Lark 中查看内容并允许或拒绝；过期或越权操作不生效。
5. 用户发送截图或文件，Agent 在指定工作目录中处理，并回传明确选择的输出文件。
6. 凭据失效、网络异常或 Agent 退出时，用户获得真实状态及修复入口，不误报任务成功。

## 3. 首版功能需求与验收

P0 为首版发布必需；P1 为首版后增强；P2 为后续扩展。所有命令名为提案。

| ID | 优先级 | 需求 | 验收条件 |
|---|---|---|---|
| SET-01 | P0 | 一次引导完成配置 | 全新用户不编辑 YAML/JSON 即可到首条测试回复；配置结果持久保存 |
| SET-02 | P0 | 引导可恢复 | 取消、超时、重跑不会丢失有效配置、重复注册服务或盲目重建应用 |
| SET-03 | P0 | Agent 检测与登录验证 | 分别显示不存在、版本不兼容、未登录、登录有效、实际请求失败；不以文件存在判定可用 |
| LARK-01 | P0 | 官方扫码注册优先 | 在支持的 Lark 租户中扫码授权后获得凭据并存入 Keychain；所有未满足的发布/权限要求可见 |
| LARK-02 | P0 | 接入已有应用 | 隐藏输入 Secret；验证应用、机器人、收消息及回复能力；不在终端回显 Secret |
| LARK-03 | P0 | 真实消息闭环 | 用户发送带一次性标记的消息，Agent 返回对应结果；不能仅以 WebSocket 连通宣告成功 |
| MSG-01 | P0 | 私聊、受控群聊、线程隔离 | 相同会话连续对话；不同用户/聊天/线程不共享上下文；群聊默认仅允许的 @消息触发 |
| MSG-02 | P0 | 消息去重与排队 | 同一事件重复投递不重复执行；同会话串行、跨会话受限并发；队列满明确提示 |
| MSG-03 | P0 | 长任务反馈与最终结果 | 收到、排队、执行、等待审批、结束状态可区分；超长结果按平台限制拆分或附件交付 |
| MSG-04 | P0 | 投递不确定可追踪 | 发送超时不盲目重复创建消息；记录待核对状态和可用的查询/幂等信息 |
| AGT-01 | P0 | 已有 Agent 可切换 | 新会话可选择通过验证的 Agent；切换默认创建新会话，不假装跨 Agent 无损继承上下文 |
| AGT-02 | P0 | 取消与终态 | 支持停止当前任务；完成、失败、取消、状态未知分别展示；成功接收请求不等于完成 |
| AGT-03 | P0 | 会话恢复 | 空闲会话重启后按适配器能力恢复；无法恢复则明确提示并创建新会话；不隐式重放有副作用任务 |
| ACL-01 | P0 | 所有者与授权用户 | 首次绑定需本机引导与 Lark 一次性校验共同完成；不能让首个陌生消息自动成为 owner |
| ACL-02 | P0 | 审批关联与校验 | 请求绑定安装、会话、任务、请求 ID、授权人和有效期；重复、过期或错会话审批无效 |
| SEC-01 | P0 | go-keyring 凭据 | Keychain 保存 Secret，普通配置仅保存引用；读取/更新后回读验证；锁定时可诊断 |
| SEC-02 | P0 | 无明文泄漏 | Secret 不进入 argv、plist、普通配置、日志或诊断包；错误脱敏；授权链接不持久记录 |
| SRV-01 | P0 | 后台服务 | install/start/stop/restart/status/uninstall 可操作且幂等；终端退出不影响服务 |
| SRV-02 | P0 | 用户级启动与恢复 | 当前用户 LaunchAgent；登录后启动，崩溃后按退避恢复；实际服务身份可读凭据和找到 Agent |
| SRV-03 | P0 | 单实例与升级兼容 | 防止前台与服务同时消费同一安装；停止服务后无孤儿 Agent；配置迁移失败保留旧状态 |
| OBS-01 | P0 | 分层状态与诊断 | 区分进程存活、凭据可读、平台在线、Agent 就绪、端到端通过；诊断默认不触发付费推理 |
| IO-01 | P0 | 图片/文件传入和产物回传 | 限制大小、类型、路径和保留期；不支持的媒体明确说明；仅暴露当前工作区允许文件 |
| PKG-01 | P0 | 可安装发行版 | 不要求 Go 开发环境；提供校验信息、干净机器安装步骤和卸载说明 |
| UX-01 | P1 | 图形化配置与状态页 | 复用同一配置服务和状态接口；不产生第二套运行逻辑 |
| AUT-01 | P1 | 定时与主动提醒 | 独立定义时区、重启补偿、投递身份和执行权限后再加入 |
| ECO-01 | P2 | 扩展平台与 Agent | 每个组合公布验证等级、版本和限制；不能只按协议握手宣传完整支持 |

## 4. 通用能力边界

AgentDock 拥有安装状态、平台连接、消息路由、授权用户、投递记录、服务状态和引导进度。已有 Agent 拥有推理、工具执行、原生会话与原生认证。AgentKit 负责可复用的运行与平台能力，具体可复用部分须在实施前完成代码验证。

首版不新建通用记忆后端、技能市场、模型供应商平台或多 Agent 自主协作系统。支持 Agent 原有技能/MCP，并在文档中说明实际加载方式；不自动改写用户全局 Agent 配置。

## 5. 平台引导要求

目标流程：环境检测 → 选择/安装 Agent → 原生登录 → Lark 扫码注册或接入已有应用 → 权限与发布检查 → Keychain 保存并回读 → 所有者绑定 → 端到端测试 → 服务安装 → 服务身份复测。

官方 SDK 的扫码注册路径见[调研](research/2026-11-07-agent-landscape.md)。若选定发布版本或租户不支持，必须说明原因并提供已有应用接入；不得把手动复制 Secret 的路径称为“自动获取”。权限清单分为聊天必需和附件/卡片可选，不为未来功能提前申请全部权限。

注册应用是外部副作用。对轮询中断或结果不确定，应先核对原流程，不能立即重新创建。持久化引导状态不保存临时敏感值，恢复令牌如确需保存也进入 Keychain 并设置生命周期。

## 6. 可靠性与安全要求

- 不承诺端到端 exactly-once；明确本地去重和平台可提供的幂等边界。
- 任务启动前记录接收与路由；终态和结果投递分别持久记录。
- 重启后，执行中任务没有明确终态则标为 interrupted/unknown，不能仅凭进程重启就重试。
- 对网络请求采用有界重试、退避与抖动；对未知副作用结果先核对。
- 首版默认有限工作目录与权限；审批交互不得被“全部允许”替代。
- 路径含空格、Unicode、符号链接、缺失目录与受限权限均有明确行为。
- 支持日志轮转与清理策略；正文日志默认关闭，诊断包先脱敏。
- 预算/令牌用量仅在 Agent 提供可解释数据时展示，不捏造跨模型费用。
- 不以周期健康检查反复启动真实推理；付费检查由用户显式触发。

## 7. 发布验收场景

必须记录 OS/架构、Agent/适配器版本、Lark 区域和应用条件、测试日期及结论。

1. 新 Mac 安装 → 已登录 Agent → 扫码/已有应用 → 首条回复 → 服务启动。
2. 未安装或未登录 Agent；安装/登录完成后从引导断点继续。
3. 私聊与两个独立群线程同时使用，不串上下文；非授权消息不启动 Agent。
4. 审批允许、拒绝、超时、重复点击、其他用户点击，行为符合关联校验。
5. 相同事件重投、长响应、附件、消息限流与发送结果不确定。
6. 断网/重连、Agent 崩溃、AgentDock 崩溃、服务重启、Mac 重新登录。
7. Keychain 锁定、Secret 失效、Agent 登录过期、PATH 变化，给出对应修复。
8. 升级失败可恢复；卸载停止服务并保留数据；数据和凭据删除需另行明确确认。

## 8. 尚需决策的项目

- 首批 Agent 是否最终锁定 Claude Code + Codex。
- macOS 最低版本与 Intel 实机覆盖，依据所选 Agent 支持范围确定。
- 安装包形式、签名/公证和 Homebrew 分发安排。
- 默认工作目录、附件大小/保留时间、并发与队列上限。
- Lark 扫码注册在目标租户的可用性，以及必要权限与发布流程。
- 对外名称/包名：已有同名项目，发布前确认。

以上未决项不阻止需求文档完成；在对应里程碑开始前落实，不视为已经获得实现或发布批准。
